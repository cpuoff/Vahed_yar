# واحد یار

واحد یار یک برنامه‌ی وب برای دانشجویان مهندسی برق (گرایش‌های الکترونیک و قدرت) دانشگاه آزاد تهران شمال است. شما درس‌های گذرانده و در حال گذراندن را علامت می‌زنید و برنامه با بررسی پیش‌نیازها، درس‌های قابل اخذ را مشخص می‌کند، برای ترم جاری درس پیشنهاد می‌دهد و واحدهای باقی‌مانده را تا فارغ‌التحصیلی بین نیمسال‌ها تقسیم می‌کند. (بر پایه‌ی چارت مصوبه‌ی ۱۷۹ مورخ ۱۴۰۳/۰۴/۱۰ کار می‌کند.)

## قابلیت‌ها

- چارت تعاملی دروس برق، معارف و عمومی با کنترل پیش‌نیاز، هم‌نیاز و قفل گرایش
- داشبورد پیشرفت و محاسبه‌ی معدل
- پیشنهاد دروس ترم جاری با رعایت سقف واحد و سقف معارف
- برنامه‌ی تحصیلی تا فارغ‌التحصیلی: چیدمان خودکار نیمسال‌ها، پخش متوازن دروس بین ترم‌ها، ویرایش دستی و تخمین تاریخ فارغ‌التحصیلی
- خروجی PDF/چاپ و بکاپ JSON
- نصب به‌صورت PWA و کارکرد آفلاین؛ داده‌ها فقط روی دستگاه کاربر ذخیره می‌شوند

## ساختار

```
js/data/           داده‌ی درس‌ها و گروه‌ها
js/logic.js        وضعیت درس‌ها، پیش‌نیاز، پیشرفت، معدل
js/suggestions.js  پیشنهاد دروس ترم
js/planner.js      موتور برنامه‌ریزی (قوانین در PLAN_RULES)
js/render*.js      رندر چارت و داشبورد
js/ui-*.js         رابط کاربری
```

## افزودن درس

درس را در `js/data/elec-courses.js` تعریف کنید و `id` آن را در گروه مناسب `elec-groups.js` بگذارید.

| فیلد | معنی |
|---|---|
| `trk` | `'elec'` یا `'power'`؛ اختصاصی همان گرایش و قفل‌کننده‌ی گرایش دیگر |
| `noLock` | بدون قفل کردن گرایش |
| `pre`, `co` | پیش‌نیاز و هم‌نیاز |
